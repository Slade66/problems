
**删除链表节点：** x 的上一个指向 x 的下一个。

**怎么知道链表的长度 n？** 必须遍历一遍。

## 第一种做法：2 次遍历 or 用切片保存链表的每个元素

- 我能想到的不用额外空间的算法是：第一轮找 n，第二轮去到 n/2-1，那就是 1.5n。

- 如果用额外空间，可以达到 n。

## 第二种做法：快慢指针

- 每轮：快的走 2 步，慢的走 1 步，走完的时候慢的就在中点。

- 无论链表长度是奇数还是偶数，循环都会执行：floor(n / 2)，因为当 2 倍速前进的快指针越界了循环就停止。由于 slow 每轮走一步，所以最终 slow 的下标 = floor(n / 2)。

- 因为是单向链表，无法回退，所以要有个变量保存 slow 指针前面的那个元素。

- 奇数链表，fast 在 n - 1 停下来，slow 在 n / 2 停下，下轮 next fast 越界，slow 在 n / 2 + 1。

- 偶数链表，fast 的第一个 next 安全，第二个 next 越界，slow 此时在 n / 2。

- **观察奇数长度链表：**

    - 链表长度为 7：下标 0 → 1 → 2 → 3 → 4 → 5 → 6

    - 两个指针的变化：

        | 轮数 | `slow` 下标 | `fast` 下标 |
        |---:|---:|---:|
        | 0 | 0 | 0 |
        | 1 | 1 | 2 |
        | 2 | 2 | 4 |
        | 3 | 3 | 6 |

    - 此时 fast 已经在最后一个节点，无法再走两步，因此停止，slow 停在下标 3，floor(7 / 2) = 3，正好是需要删除的节点。

- **观察偶数长度链表：**

    - 链表长度为 4：下标 0 → 1 → 2 → 3

    - 两个指针的变化：

        | 轮数 | `slow` 下标 | `fast` 下标 |
        |---:|---:|---:|
        | 0 | 0 | 0 |
        | 1 | 1 | 2 |
        | 2 | 2 | nil |

    - 此时：slow 下标 = 2，floor(4 / 2) = 2，正好是要删除的节点。
