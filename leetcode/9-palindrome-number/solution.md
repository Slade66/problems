
## 题意理解

- 如果一个数字从左右两边同时往中间读，遇到的每一个元素都一样，那它就是回文数。

## 方法一

- 去数字的后半部分，再镜像翻转，看看相不相等。

- 循环条件是 x > half：如果前半部分 > 后半部分，如 1211，后面会取多一位，x != half；如果后半部分 > 前半部分，如 1231，正常停下，不相等。

- 奇数的情况，如 121，是回文数，但是前半部分会比后半部分多 1 位，要特殊处理：如果是奇数，那么后半部分去掉最后一位再跟前半部分比较。但是像 10 这种尾部为 0 的数字会出问题，因为前 0 后 1，而 1 / 10 == 0，误判回文串。

- 0 肯定不是回文串，因为没有数字以 0 结尾反过来是 0 开头，所以末尾是 0 直接 false，除非本身就是 0，and we are done.
