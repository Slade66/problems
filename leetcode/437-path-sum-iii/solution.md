
## 题意理解

- **核心一句话：** 任意一段“从上往下”的路径和（相邻节点相加）= `targetSum`，数有几条。

- 两条约束直接推导出解法结构：

    1. **路径可以从任意节点开始** → 不能只从 root=10 开始往下找，而必须让每个节点都当一次起点 → 需要一个“枚举起点”的过程。

    2. **路径只能从父节点走向子节点** → 不需要走回头路，单向累加即可。

## 方法一：两层遍历（枚举起点 + 固定起点向下累加）

- 核心思想：外层循环遍历每一个节点（枚举起点），内层处理以当前节点为起点、向下查找有多少条路径和为 `targetSum`。

- 对“从固定起点向下搜索”这个子问题，函数至少需要知道两件事：

    1. 现在走到了哪个节点（节点的值）；
    2. 从起点走到当前节点之前，累计了多少。

    （目标值 `targetSum` 作为参数一并传入。）

- 每到一个真实节点：拿当前累计和加上自己，如果 `== targetSum` 就计数 + 1。

- 命中后要继续往下搜索：因为可能先累计 -10，再 +10 又等于 `targetSum`。

- 遇到 nil：没有节点可以继续处理 → 当前分支贡献 0 → 返回。

- 结果累加方式：可以返回找到的数量，最后相加；也可以使用外部计数器。

- 概括：
    1. 枚举每一个起点；
    2. 从该起点向下累加；
    3. 每到一个真实节点就检查；
    4. 命中后继续搜索；
    5. 遇到 nil 结束当前分支。
