# DP 解法：以每个数结尾的最长递增序列

## 一、核心问题

- **目标：** 判断数组里有没有长度为 3 的严格递增子序列，也就是是否存在 `i < j < k`，并且 `nums[i] < nums[j] < nums[k]`。

## 二、怎么计算

- **子问题：** 不直接问整个数组有没有长度为 3 的递增子序列，而是逐个问：“以 `nums[i]` 结尾，最长能串多长？”

- **状态含义：** `dp[i]` 表示以 `nums[i]` 结尾时，最长严格递增子序列的长度。它不是“从数组开头到 i 的总长度”。

- **状态转移：** 计算 `dp[i]` 时，只看 `i` 前面那些比 `nums[i]` 小的数。

    1. 先默认 `dp[i] = 1`，表示自己单独站成一队。
    2. 枚举每个 `j < i`。
    3. 如果 `nums[j] < nums[i]`，说明 `nums[i]` 可以接在 `nums[j]` 后面。
    4. 更新为 `dp[i] = max(dp[i], dp[j] + 1)`。

- **提前结束：** 只要某个 `dp[i] >= 3`，就说明已经找到三个递增的数，可以直接返回 `true`。

## 三、例子

- **示例推演：** 数组是 `[5, 1, 5, 5, 2, 5, 4]`，我们逐个问：“以你结尾，最长能串多长？”下面只推到第一次满足 `dp[i] >= 3` 的位置，后面的 `4` 不需要再算。

    | i | 数值 | 前面谁比我小？ | 能接在谁后面？ | `dp[i]` | 含义 |
    | - | - | - | - | - | - |
    | 0 | `5` | 没有 | 只能自己站着 | `1` | `[5]` |
    | 1 | `1` | `5` 比 `1` 大，不行 | 没人能接 | `1` | `[1]` |
    | 2 | `5` | `1` 比 `5` 小 | 接在 `1` 后面：`[1, 5]` | `2` | 长度 2 |
    | 3 | `5` | `1` 比 `5` 小；前面的 `5` 不算，因为不是严格小于 | 接在 `1` 后面：`[1, 5]` | `2` | 长度 2 |
    | 4 | `2` | `1` 比 `2` 小 | 接在 `1` 后面：`[1, 2]` | `2` | 长度 2 |
    | 5 | `5` | `1 < 5`，`2 < 5`；前面的 `5` 不算，因为不是严格小于 | 接在 `2` 后面：`[1, 2, 5]` | `3` | `>= 3`，找到了 |

    `i = 5` 这一步是关键：

    1. `nums[5] = 5`。
    2. 前面 `nums[4] = 2`，而且 `2 < 5`。
    3. `dp[4] = 2`，说明以 `2` 结尾已经能串出长度 2 的序列 `[1, 2]`。
    4. 那 `5` 接在 `2` 后面，就是 `[1, 2, 5]`，长度 3。
    5. 所以 `dp[5] = 3`，直接返回 `true`。

## 四、dp 的语义和价值

- **核心本质：** 动态规划的本质是“前人栽树，后人乘凉”。后面的计算利用前面的计算结果，不要重新算。

- **dp 的语义：** 普通缓存，存的是“查过的结果，下次别查了”。但 `dp[i]` 存的是“以第 i 个数为结尾，这个问题的最优答案是什么”。它有一个很强的语义：最优子结构。不是随便什么中间结果都配叫 `dp`，只有那种“后面能直接拿来当基石”的最优解，才进 `dp` 数组。

- **不用 dp 的代价：** 还是看同一个例子里的 `nums[5] = 5`。如果它不 care `nums[4] = 2` 的 `dp[4]`，就要亲自从头数一遍。

    1. 看 `nums[1] = 1`：比我小，能接，从 `1` 开始数：`[1, 5]`，长度 2。
    2. 看 `nums[4] = 2`：比我小，能接，但要先知道 `2` 前面有没有更小的数。
    3. 再回头看 `nums[1] = 1`：`1 < 2`，所以以 `2` 结尾能串出 `[1, 2]`，长度 2。
    4. 那 `5` 接在 `2` 后面，就是 `[1, 2, 5]`，长度 3。

    你发现了吗？`nums[5]` 在算自己的时候，把 `nums[4]` 刚才算过的 `[1, 2]` 又重算了一遍。数组很长时，后面每个数都把前面的历史翻出来重数一遍，复杂度直接爆炸。

    所以这里的动态规划，就是每个位置算一次，存下来，后面的位置直接拿来用。有了这个“缓存本”，虽然还是双重循环，但内层只需要比较和取最大值，不需要重新追溯整条链。

- **命名习惯：** 叫 `dp` 更多是刷题和论文里的习惯，就像循环变量喜欢叫 `i`、`j` 一样。算法工程师看到 `dp` 就知道：“这是动态规划，里面存的是子问题最优解”。
